# PRIV: 15. LGPD e privacidade

| ID | Pri | Controle | Exigência / evidência |
|---|---|---|---|
| PRIV-01 | P0 | Mapa de dados | Identificar coleta, processamento, compartilhamento e armazenamento. |
| PRIV-02 | P0 | Base legal | Documentar fundamento apropriado por finalidade. |
| PRIV-03 | P0 | Minimização | Coletar somente o indispensável. |
| PRIV-04 | P0 | Finalidade | Evitar desvio de uso sem base adequada. |
| PRIV-05 | P0 | Acesso a dados | Restringir leitura e exportação por função. |
| PRIV-06 | P1 | Transparência | Publicar política clara e atualizada. |
| PRIV-07 | P1 | Direitos dos titulares | Possuir fluxos para solicitações aplicáveis. |
| PRIV-08 | P0 | Retenção | Eliminar dados quando a retenção deixar de ser necessária e legalmente exigida. |
| PRIV-09 | P1 | Terceiros | Avaliar contratos e operadores de dados. |
| PRIV-10 | P1 | Transferência internacional | Avaliar base e mecanismos legais correspondentes. |
| PRIV-11 | P0 | Comunicação de incidentes | Avaliar risco e cumprimento das regras da ANPD. |
| PRIV-12 | P1 | Registros de decisão | Documentar conformidade e tratamento de risco. |
| PRIV-13 | P1 | RIPD | Elaborar relatório de impacto quando aplicável. |
| PRIV-14 | P1 | Privacy by design | Incluir privacidade em projetos e mudanças. |
| PRIV-15 | P1 | Analytics e logs | Minimizar coleta involuntária de informações pessoais. |
