# REL: 31. Release gates por plataforma

| ID | Pri | Controle | Exigência / evidência |
|---|---|---|---|
| REL-01 | P0 | Zero P0 explorável | Corrigir ou mitigar de modo verificável vulnerabilidades críticas. |
| REL-02 | P0 | Autorização aprovada | Testes de isolamento de usuários, tenants e roles. |
| REL-03 | P0 | Suite automatizada | Unidade, integração, E2E e regressão aprovados. |
| REL-04 | P1 | Crashes triados | Nenhuma regressão relevante de estabilidade. |
| REL-05 | P0 | Restauração comprovada | Backup testado e objetivos atendidos. |
| REL-06 | P0 | Contrato cliente/API | Versões ainda suportadas operam corretamente. |
| REL-07 | P0 | Android release | Manifest, assinatura, permissões e build sem debug. |
| REL-08 | P1 | Android vitals | ANR, lifecycle e aparelhos representativos testados. |
| REL-09 | P0 | iOS release | Entitlements, Keychain, ATS, privacidade e assinatura. |
| REL-10 | P1 | iOS beta | TestFlight e dispositivos reais validados. |
| REL-11 | P0 | Desktop assinado | EXE, pacote e instalador íntegros. |
| REL-12 | P0 | Atualizador testado | Interrupção, verificação, rollback e migrações. |
| REL-13 | P0 | Privilégios desktop | IPC, bibliotecas, filesystem e elevação revisados. |
